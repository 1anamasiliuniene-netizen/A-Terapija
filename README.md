# A Terapija

A Terapija is a bilingual Django web application for a therapy and wellbeing service. The site supports public content, service discovery, therapist profiles, appointment booking, wellbeing assessment, and role-based dashboards for clients, therapists, and administrators.

The public experience is available in Lithuanian and English. Lithuanian is the default language.

## Features

- Bilingual public pages for services, articles, advice, contact, and about content.
- Editable about page content in Lithuanian and English.
- Client registration, login, profile management, and appointment booking.
- Therapist dashboards for profile, services, availability, bookings, and payment tracking.
- Admin dashboards for services, therapists, clients, bookings, articles, advice, contact messages, wellbeing questions, and page content.
- Wellbeing assessment with suggested services.
- Email-ready password and account flows.
- Responsive UI with project-level CSS tokens and reusable templates.

## Tech Stack

- Python
- Django
- SQLite for local development
- Bootstrap 5
- django-crispy-forms
- crispy-bootstrap5
